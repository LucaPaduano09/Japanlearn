# Kakitai — notes for Claude

Spec and milestones: `BOOTSTRAP.md`.

- Next.js 16 App Router with `output: 'export'`. NO server features (API routes, server actions, middleware/proxy).
- Capacitor 8 wraps `out/`. After web changes: `npm run cap:sync`.
- Anything using window/canvas/Dexie/Capacitor must be a client component, with browser APIs guarded.
- Handwriting logic lives in src/lib/strokes; it must stay pure TS and unit-tested.
- Grading thresholds are constants in compare.ts; don't scatter magic numbers.
- Content JSON in public/data is generated by scripts/build-data.ts; don't hand-edit it.
- UI strings: `src/lib/i18n/en.ts` and `it.ts` (same shape, type-checked); read them through `strings` from `src/lib/strings.ts` while rendering, never in module-level constants (LocaleGate re-renders the app when the language changes). Pages that show text must be client components. Kanji/word meanings are English data in both languages.
- The learning path (src/lib/path/stages.ts, pure + tested) is the only way new items are introduced: hiragana rows → katakana rows → N5 → N4, each level being its themed kanji lessons (`LESSONS`, `LESSONS_N4` in lessons.ts) in stages of 5, every lesson followed by the words it makes readable; leftover words come last. Each stage has an intro (what the row is) and reward words that use only characters learned so far (a test enforces it). Reviews (src/components/review) only show due cards.
- SRS: decks and card types in src/lib/srs/decks.ts, review planning in queue.ts, ts-fsrs wrapper in scheduler.ts (all pure, unit-tested). Dexie tables in src/lib/db/schema.ts; changing a table needs a new `db.version()` and, if backups change shape, a `BACKUP_VERSION` bump in backup.ts.
- Settings live in the Dexie `settings` table via src/store/settings.ts; `update()` is ignored until `load()` finished. AppShell (layout) loads them, applies the theme and hides the splash.
- Icons/splash: edit scripts/make-icons.ts, then `npm run icons:build` and `npx capacitor-assets generate` (colors in docs/store-listing.md). Store copy and the device checklist are in docs/.
- Speaking: kana and vocab items have a `speak` card (read it aloud), and their stage intro has an ungraded "Say it" step after "Meet" (ItemIntro; kanji alone skip both). Shared hook/UI in src/components/cards/speech.tsx. Recognition in src/lib/native/stt.ts (plugin in the app, Web Speech API in browsers); matching in src/lib/speech/match.ts (pure, tested). Card types the device can't do are passed as `skip` to planReviews/countDue/nextDue; `addMissingCards` gives already-learned items cards of newly added types. The plugin ships no Package.swift: `patches/` adds one (patch-package, run on postinstall) — keep it when upgrading the plugin.
- Words with kanji show their reading as furigana (`<Furigana>` in src/components/ui, split per kanji by `furigana()` in src/lib/content/furigana.ts, pure + tested); don't put the kana reading beside the word.
- Run `npm test` and `npm run build` before saying a task is done (`npm run e2e` for flows).
- Keep KanjiVG/EDRDG attribution intact.
